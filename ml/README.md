# Baseline model

The baseline uses two independent scikit-learn pipelines. Each pipeline
combines a TF-IDF vectorizer with word unigrams and bigrams, sublinear term
frequency, and balanced logistic regression. One pipeline predicts `purpose`;
the other predicts `urgency`.

Training combines the 12 C16 fixture emails with 120 labelled synthetic
emails generated by `gen_synthetic.py`. The synthetic data covers requests,
corrections, resolutions, duplicates, status updates, FYI messages,
commitments, questions, blockers, and instruction-like injection text. This
data is synthetic, generated by us, and not a benchmark.

The training script performs shuffled stratified five-fold cross-validation,
writes per-class reports and confusion-matrix PNGs, then fits on all rows.
The checked-in run reports 1.000 accuracy for both purpose and urgency on the
fixture comparison, with seeded critical recall of 6/7 (0.857). These numbers
should not be treated as production performance because the fixture and
training examples share the same bounded vocabulary and patterns.

`outputs/predictions.json` contains one prediction per fixture email with
`purpose`, `urgency`, and a combined confidence score. The application may
use these predictions as an optional assist. The labelled rules and template
fallback remain the default path, so a missing model output does not prevent
triage or draft review.

To reproduce:

```bash
python3 ml/gen_synthetic.py --seed 16
python3 ml/train_baseline.py
python3 ml/eval.py
```

The local model files are ignored and are not required to run the evaluation
report from the checked-in predictions.
