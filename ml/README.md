# ml/ — optional model assist (owner: C)

Outputs consumed by the app (all JSON, keyed by email_id / thread_key):
- `outputs/predictions.json` — baseline classifier predictions for the 12 fixture emails
- `outputs/model_eval.json` — precision/recall/F1 vs `data/labels/C16_labels.json`
- `outputs/draft_variants.json` — Ollama draft variants that passed the forbidden-terms check

Setup (MacBook):
```
cd ml && python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
ollama pull llama3.1:8b
```
